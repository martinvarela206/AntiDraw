# AntiDraw - SVG Vector Editor

Integrated vector graphics editor for SVG files inside VS Code, inspired by CorelDraw and Figma.

## Features
- Full interactive SVG canvas with zoom, pan, and transform controls.
- Top and Left Rulers with customizable units (px, mm, cm, in) and scales.
- Interactive guide lines: drag from rulers, select, delete (via drag or `Supr`), and angle/pivot manipulation on double-click.
- External sidecar `.json` metadata persistence.
- Node and path editing tools with asymmetric, smooth, and symmetric Bézier handles.
- Boolean vector operations and alignment tools.
